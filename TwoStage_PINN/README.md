# PINN Adam → L-BFGS 两阶段优化实验

## 1. 实验目标

本实验测试 PINN 中的两阶段优化策略：

**先使用 Adam 训练，再切换到 L-BFGS。**

主要比较两种训练方式：

-   **Adam-only**：Adam 训练 20,000 轮；
-   **Adam → L-BFGS**：先使用 Adam 训练 15,000 轮，再从相同 checkpoint
    切换到 L-BFGS。

实验选择两个问题：

1.  Burgers 方程参数识别；
2.  Allen--Cahn 方程正问题。

目的是观察 Adam → L-BFGS 是否一定优于继续使用
Adam，以及不同问题上的效果是否存在差异。

------------------------------------------------------------------------

## 2. Burgers 参数识别

### 2.1 实验设计

Burgers 实验用于识别方程中的两个未知参数 `lambda_1` 和 `lambda_2`。

真实参数为：

-   `lambda_1 = 1.0`
-   `lambda_2 ≈ 0.003183`

两个训练分支使用相同的前 15,000 轮 Adam 结果，然后分别：

-   继续使用 Adam 训练 5,000 轮；
-   切换到 L-BFGS。

这样可以直接比较优化器切换带来的影响。

### 2.2 实验结果

  指标                  Adam-only 20k   Adam 15k → L-BFGS
  ------------------- --------------- -------------------
  Total Loss             **2.355e-4**            2.930e-4
  lambda_1               **0.985134**            0.984174
  lambda_2               **0.004770**            0.004876
  lambda_1 相对误差         **1.49%**               1.58%
  lambda_2 相对误差        **49.86%**              53.17%

### 2.3 实验效果

Burgers 实验中，两种训练方式的结果非常接近。

切换到 L-BFGS 后没有得到明显改善。本次运行中，Adam-only 的 Total Loss
和参数识别误差反而略低。

因此，对于当前 Burgers 参数识别任务：

> **Adam → L-BFGS 没有表现出明显优势。**

这说明两阶段优化并不是在所有 PINN 问题上都能带来更好的结果。

------------------------------------------------------------------------

## 3. Allen--Cahn 正问题

### 3.1 实验设计

Allen--Cahn 实验用于预测完整的时空解场。

训练使用：

-   500 个观测点；
-   20,000 个 PDE collocation points；
-   网络结构 `[2, 64, 64, 64, 64, 1]`。

同样先共同使用 Adam 训练 15,000 轮，然后分成：

-   Adam 继续训练到 20,000 轮；
-   Adam 15,000 轮后切换到 L-BFGS。

除了训练 Loss，还使用完整参考解计算 Relative L2
Error，用于评价最终解场的预测精度。

### 3.2 实验结果

  指标            Adam-only 20k   Adam 15k → L-BFGS
  ------------- --------------- -------------------
  Total Loss           2.232e-4        **7.738e-6**
  Data Loss            2.258e-5        **5.629e-6**
  PDE Loss             2.006e-4        **2.109e-6**
  Relative L2          8.853e-3        **4.419e-3**

相比 Adam-only，Adam → L-BFGS：

-   Total Loss 降低约 **96.5%**；
-   PDE Loss 降低约 **99.0%**；
-   Relative L2 Error 降低约 **50.1%**。

### 3.3 实验效果

Allen--Cahn 上两种训练方式出现了明显差距。

继续使用 Adam 时，模型虽然已经处于较低 Loss 区域，但后期改善有限。

切换到 L-BFGS 后：

-   Total Loss 大幅下降；
-   PDE Loss 接近下降两个数量级；
-   完整解场的 Relative L2 Error 约降低一半。

因此，对于当前 Allen--Cahn 问题：

> **Adam → L-BFGS 明显优于继续使用 Adam。**

这里的提升不仅体现在训练 Loss 上，也体现在最终解场精度上。

------------------------------------------------------------------------

## 4. 综合结果

  实验                 Adam → L-BFGS 效果
  -------------------- ------------------------------
  Burgers 参数识别     无明显提升，Adam-only 略优
  Allen--Cahn 正问题   明显提升，解场误差约降低一半

两个实验得到的结果并不相同。

在较容易优化的 Burgers 参数识别中，Adam 已经能够得到较好的结果，切换
L-BFGS 没有继续改善。

在 Allen--Cahn 中，Adam 后期的优化效果明显变弱，而 L-BFGS 能够继续降低
Loss，并提高完整解场的预测精度。

因此，本实验的主要结论是：

> **Adam → L-BFGS 的效果与具体问题有关，并不是所有 PINN 都需要切换到
> L-BFGS。**

> **当 Adam 在训练后期仍存在明显的优化困难时，切换到 L-BFGS
> 可能带来更明显的收益。**

当前实验只包含两个
PDE，因此这个现象还不能作为一般规律，但可以作为后续选择优化策略和设计更大规模实验的参考。
